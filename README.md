# 🛡️ Women Safety & Emergency Assistance Platform

A full-stack web application designed to enhance women's safety by providing real-time emergency support, live location tracking, and instant communication with nearby volunteers.

## 🚀 Features
- 🔴 One-click SOS alert system
- 📍 Real-time location tracking
- 👥 Volunteer-based emergency response
- 🔐 Secure authentication (JWT)
- 📊 Admin dashboard for monitoring emergencies
- ⚡ Real-time updates using Socket.IO

## 🛠️ Tech Stack
- Frontend: React, Vite, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB (with Mongoose)
- Real-time: Socket.IO

## ▶️ How to Run
bash cd server npm install npm run dev  cd client npm install npm run dev 

## 🌐 Access
